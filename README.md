# RatioBackup

Sichert Fotos, Videos, Downloads und WhatsApp vom Xiaomi 18 Pro jeden Abend ab 20 Uhr übers Heim-WLAN auf den Windows-PC – als Spiegel mit 30-Tage-Papierkorb.

- `android/` – Handy-App (Kotlin)
- `pc/` – Taskleistenprogramm für Windows (C#/.NET 8)
- `docs/PROTOCOL.md` – Protokoll zwischen beiden
- `docs/superpowers/` – Design und Umsetzungsplan

## Download (Testversion)
- Handy: https://github.com/ratioAI/ratioBackup/releases/latest/download/RatioBackup.apk
- PC: https://github.com/ratioAI/ratioBackup/releases/latest/download/RatioBackup-PC.exe

Gebaut und getestet wird automatisch mit GitHub Actions; Testergebnisse je Commit liegen im Branch `ci-results`.
